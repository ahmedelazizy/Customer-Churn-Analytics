# Customer Churn Analytics

## Project Overview

**Customer Churn Analytics** is a data analytics project designed to understand customer churn and identify the key factors that influence customer retention.

The project analyzes customer demographics, subscription details, usage behavior, payment methods, and customer service interactions to discover churn patterns and identify high-risk customer segments.

The complete workflow combines **Python, SQL Server, and Power BI** to transform raw customer data into meaningful insights and actionable business recommendations.

## Project Objectives

* Identify the main factors associated with customer churn.
* Analyze customer behavior and subscription patterns.
* Identify high-risk customer segments.
* Understand payment and usage behaviors related to churn.
* Create interactive dashboards for business analysis.
* Provide actionable insights to support customer retention strategies.

## Project Workflow

**Raw Data → Data Cleaning → Data Analysis → Visualization → Business Insights**

* **Python:** Data cleaning, preprocessing, and preparation.
* **SQL Server:** Data exploration, querying, and analytical analysis.
* **Power BI:** Interactive dashboards, KPIs, and data visualization.
